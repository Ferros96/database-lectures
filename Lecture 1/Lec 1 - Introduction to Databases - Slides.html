Traditional database applications

Databases and database systems touch most aspects and activities of our lives. Traditional applications store textual or numeric data.

Banks

Accounts, customers and transactions.

Airline reservations

Flights, seats and bookings.

Hotels

Rooms, guests and reservations.

Library catalogs

Computerized catalog of books and loans.

New applications of database systems

Big data (NoSQL)

Social media sites such as Facebook and Twitter need huge databases of nontraditional data: posts, tweets, images and video clips. New big data storage or NOSQL systems were created to manage them.

Multimedia databases

Store and manage multimedia content.

Geographic information systems (GIS)

Store and analyze geographic data.

Data warehouses & OLAP

Used in many companies to extract and analyze useful business information from very large databases to support decision making.

Real-time & active databases

Used to control industrial and manufacturing processes.

What is a database?

DEFINITION
Database

A collection of related data.

And what is “data” here?

Data Known facts that can be recorded and that have implicit meaning.
Related The facts belong together; they describe the same part of the world.

What is data?

DEFINITION
Data

Unorganized information that is processed to make it meaningful.

Data can consist of

FactsObservationsPerceptionsNumbersCharactersSymbolsImagesA mix of these
Data can be categorized by the level and rigidity of its structure: structured, semi-structured or unstructured.
62153 · Intro to Database Systems · Lecture 109 / 24
02 · Databases and data

Implicit properties of a database

Represents part of the real world

Called the miniworld or the universe of discourse (UoD). Changes to the miniworld are reflected in the database.

Logically coherent

A logically coherent collection of data with some inherent meaning. A random assortment of data is not a database.

Built for a specific purpose

Designed, built and populated with data for a specific purpose, with an intended group of users and some preconceived applications.

Database Management System (DBMS)

DEFINITION
DBMS

A computerized system that enables users to create and maintain a database.

A general-purpose software system that facilitates

Defining databases
Constructing databases
Manipulating databases
Sharing databases among various users and applications
62153 · Intro to Database Systems · Lecture 112 / 24
03 · Database Management System

Database building: define, construct, manipulate

Defining

Specifying the data types, structures and constraints of the data. The database definition is also stored by the DBMS in a database catalog or dictionary; it is called meta-data.

Constructing

Storing the data on some storage medium that is controlled by the DBMS.

Manipulating

Querying the database to retrieve specific data, updating it to reflect changes in the miniworld, and generating reports from the data.

62153 · Intro to Database Systems · Lecture 113 / 24
03 · Database Management System

Database building: sharing

Sharing

Allows multiple users and programs to access the database simultaneously.

Application programs

An application program accesses the database by sending queries or requests for data to the DBMS.

62153 · Intro to Database Systems · Lecture 114 / 24
03 · Database Management System

Protecting and maintaining the database

System protection

Against hardware or software malfunction (crashes).

Security protection

Against unauthorized or malicious access.

Long-term maintenance

A large database may have a life cycle of many years, so the DBMS must let the system evolve as requirements change over time.

Database + DBMS software together = a database system.
62153 · Intro to Database Systems · Lecture 115 / 24
03 · Database Management System

A simplified database system environment

  1. 1
    Users and programmers work through application programs and queries.
  2. 2
    The DBMS software processes those queries and programs.
  3. 3
    It then accesses the stored data, using the stored database definition (meta-data) to understand it.

Key takeaways

  1. 01

    A database is a collection of related data; data are known facts that can be recorded and have implicit meaning.

  2. 02

    A DBMS is general-purpose software for defining, constructing, manipulating and sharing databases.

  3. 03

    Database + DBMS software = database system.

  4. 04

    Design moves from requirements → conceptual → logical → physical.
