A · Vocabulary

Q1
In the relational model, a row of a table is called a…
A row is a tuple.
Q2
A column header is called an…
A column header is an attribute.
Q3
The table itself is called a…
In the relational model, the table is called a relation.
Q4
The set of possible values that can appear in a column is its…
The data type describing the values that can appear in a column is represented by a domain of possible values.
Q5
A relation schema R(A1, A2, …, An) is made up of…
A relation schema is a relation name R plus a list of attributes A1 … An.
Q6
A relation state r(R) is…
r(R) is a set of n-tuples r = {t1, t2, …, tm}.
02

B · True or false?

T/F7
Two relation states that contain the same tuples in a different order represent the same relation.
A relation is a set of tuples, and tuple ordering is not part of a relation definition.
T/F8
The degree of a relation increases when we insert new tuples.
Degree is the number of attributes. Inserting tuples changes the state, not the degree.
T/F9
Each value in a tuple must be an atomic value.
Composite and multi-valued attributes are not allowed in a cell.
T/F10
A domain is a set of atomic values.
That is the definition of a domain D.
T/F11
NULL is used when the value of an attribute within a particular tuple is unknown.
The values of some attributes within a particular tuple may be unknown; these are shown as NULL.
T/F12
Composite attributes are stored as one combined value in a single attribute.
Composite attributes are represented only by their simple component attributes.

Q16
For each domain, give a data type or format: (a) Phone_numbers, (b) Grade_point_averages, (c) Employee_ages.
MODEL ANSWER(a) A character string of the form ddd-dddd, where each d is a decimal digit. (b) A real (floating point) number between 0 and 4. (c) A whole number (integer) between 15 and 80.
Q17
A student has two home phone numbers. Explain why we can’t put both in the HomePhone cell, and how the relational model represents them.
MODEL ANSWEREach value in a tuple must be atomic, so a cell cannot hold a list. HomePhone would be a multi-valued attribute, and multi-valued attributes must be represented by a separate relation (for example one tuple per student-and-phone pair).
