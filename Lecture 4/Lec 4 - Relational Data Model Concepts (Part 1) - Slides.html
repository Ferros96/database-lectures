What is a relation schema?

DEFINITION
R (A1, A2, …, An)

A relation schema is made up of a relation name R and a list of attributes A1, A2, …, An.

Reading it

R The relation name, e.g. STUDENT.
A1 … An The attributes, e.g. Name, SSN, Age.

What is a domain?

A domain D is a set of atomic values. Examples:

Phone_numbers

The set of 7-digit phone numbers valid in a particular area code.

Social_security_numbers

The set of valid 9-digit social security numbers.

Names

The set of names of persons.

Grade_point_averages

Possible computed GPAs; each a real (floating point) number between 0 and 4.

Employee_ages

Possible ages of a company’s employees; each between 15 and 80 years old.

Academic_department_names

Such as Computer Science, Economics and Physics in a university.

Data type and relation state

Data type (format)

Specified for each domain. Example: Phone_numbers can be declared as a character string of the form ddd-dddd, where each d is a numeric (decimal) digit.

Relation state r(R)

A relation state r of the relation schema R(A1, A2, …, An), denoted r(R), is a set of n-tuples r = {t1, t2, …, tm}.

Ordering of tuples is not important

A relation is defined as a set of tuples.
Tuples in a relation do not have any particular order.
Tuple ordering is not part of a relation definition.

02 · Characteristics of relations

Atomic values and nulls

Atomic values

Each value in a tuple is an atomic value.

No composite or multi-valued attributes

Multi-valued attributes must be represented by separate relations; composite attributes are represented only by their simple component attributes.

Nulls

The values of some attributes within a particular tuple may be unknown (shown as NULL, e.g. a missing Office_phone).

Key takeaways

  1. 01

    The relational model represents a database as a collection of relations (tables).

  2. 02

    Tuple = row, attribute = column header, relation = table, domain = set of allowed atomic values.

  3. 03

    A relation schema R(A1, …, An) has degree n; a relation state r(R) is a set of n-tuples.

  4. 04

    Tuple order does not matter; values are atomic and may be NULL when unknown.
